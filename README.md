## How I work

- **AI-assisted development:** I use AI tools (Claude, Copilot-style assistants) daily to plan, scaffold, review and debug. I treat the output as a draft: I read it, test it and own what ships.
- **Clean code and testing:** small, readable modules, typed code (TypeScript, Zod), unit tests with Vitest, E2E and accessibility checks with Playwright and axe.
- **Engineering workflow:** one branch and one PR per change, Conventional Commits, protected branches with required CI, squash merge.
- **Production habits:** timeouts, retries with backoff and rate-limit handling when calling third-party APIs; measuring (Lighthouse medians) before optimizing.
- **Communication:** bilingual documentation (EN/PT), clear READMEs and PR descriptions, comfortable working asynchronously with remote teams.
- **Self-directed learner:** I moved from biotechnology and options trading into software on my own, and I ship projects end to end to learn.
